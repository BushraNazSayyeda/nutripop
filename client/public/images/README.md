## Tips
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`
- Keep file sizes under **300 KB** for fast page loads
- WebP format is recommended for best compression/quality ratio
- The site uses `object-fit: contain` for product images and `object-fit: cover` for scene/hero images
